# Konsido 3PL Website

Statisk hemsida för Konsido 3PL, redo för GitHub Pages.

## Filer

- `index.html` – startsida
- `styles.css` – all styling
- `script.js` – mobilmeny
- `CNAME` – kopplar GitHub Pages till `konsido.se`
- `assets/images/` – logotyp och lagerbilder

## Ladda upp på GitHub

1. Skapa ett nytt repository, t.ex. `konsido-site`.
2. Ladda upp alla filer i denna mapp till repositoryts root.
3. Gå till **Settings → Pages**.
4. Välj branch `main` och folder `/root`.
5. Lägg in custom domain: `konsido.se`.
6. Peka DNS hos domänleverantören enligt GitHub Pages instruktioner.
